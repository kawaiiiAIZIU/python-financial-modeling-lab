# 课程概念图生成记录

本目录中的九张章首图由图像生成模型制作，用于建立概念关系和学习动机；它们**不是数据图，也不提供精确数值证据**。所有带坐标、单位、样本统计或模型比较的图均由 Notebook 中的 Python 代码生成。

## 统一视觉约束

- 16:9 横向，暖白纸张背景，哑光材质的编辑插画风格；
- 钴蓝为主色，安全橙用于警示，炭灰与少量金色辅助；
- 保留约 8% 安全边距与足够留白；
- 不生成文字、字母、数字、公式、坐标轴、品牌、界面或水印；
- 中文标题、变量、单位、读图步骤和适用边界全部放在 Notebook 的 Markdown 中。

## 各章图意

| 文件 | 生成提示的核心构图 | Notebook中的准确读法 |
|---|---|---|
| `00_c_to_python_pipeline.png` | C式机械结构与Python式模块把同一输入送入财富路径 | 语言表达不同，计算规则与边界检查仍需一致 |
| `01_financial_choices.png` | 小林的资金连接现金、债权、股权和基金等选择 | 金融工具对应不同权利、现金流和风险，不是收益排名 |
| `02_time_value.png` | 时间轴上的向前复利与向后贴现 | 两个方向是同一增长因子的逆运算 |
| `03_bond_mechanism.png` | 固定付款时间表与利率—价格跷跷板 | 合同现金流不变时，比较利率上升会压低现值 |
| `04_market_mechanism.png` | 企业份额进入资产篮子，再连接市场供需 | 股权、基金持有与成交价格是不同层次 |
| `05_data_pipeline.png` | 乱序、缺失、重复数据通过检查、时间闸门和隔离区 | 清洗不是删掉麻烦行，而是保留证据并控制当时可知信息 |
| `06_returns_wealth.png` | 同一本金经历价格变化、股息与追加资金后形成不同财富路径 | 资产收益、外部现金流和个人财富不可混为同一口径 |
| `07_probability_sampling.png` | 总体容器、重复样本和宽窄不同的结果堆 | 总体模型、一次样本和样本统计量是不同对象 |
| `08_risk_lenses.png` | 波动带、峰谷落差、尾部容器、压力冲击与杠杆 | 风险是多维观察，单一指标不能证明安全 |

若以后重新生成图片，应保留原图与提示记录，先在 Notebook 中验证构图含义，再更新引用。
