# AI时代的Python量化金融交互教程

这是一套面向本科二年级学生的交互式课程。学生已经学过 C 语言、线性代数和高等数学，但不要求具备金融学、概率统计或量化投资基础。

课程采用三条同步推进的主线：

1. **金融概念线**：货币、现金流、利率、股票、债券、基金、收益、风险、组合、交易与衍生品。
2. **数学模型线**：函数、概率、统计、矩阵、优化、时间序列和随机模拟。
3. **Python能力线**：语法恢复、NumPy、pandas、Matplotlib、交互实验、模型实现、测试和可复现研究。

- [01_金融量化与Python初体验.ipynb](01_金融量化与Python初体验.ipynb)：从一名大学生的 10,000 元出发，认识金融系统、现金、债券、股票、基金、收益、风险和模拟研究。

## 建议使用方式

1. 在 PyCharm 中打开一个 Notebook。
2. 从顶部开始逐单元运行，不要跳过“预测”和“观察问题”。
3. 操作滑块、修改参数，并在 `### 我的回答` 下填写文字。
4. 保存 Notebook 后，在独立 Codex 窗口中要求检查当前回答和运行输出。
5. 一章结束后执行 **Restart Kernel and Run All**，确认结果能够从零复现。

Notebook 中的投资参数均为教学假设，不构成收益承诺或投资建议。

## 环境安装

建议为本项目创建独立 Python 环境，然后安装：

```bash
python -m pip install -r requirements.txt
```

如暂未安装 `ipywidgets` 或 `plotly`，基础示例仍能运行；交互单元会给出安装提示并使用静态后备图。

## 资料来源原则

课程优先采用监管机构、交易所、官方文档、教材和原始论文。原始参考教材为 Yves Hilpisch《Python金融大数据分析》（2015 中文版）；课程会保留其“金融问题与计算实践结合”的优点，但不会照搬已经过时的软件安装、Web 集成或具体数据接口。
