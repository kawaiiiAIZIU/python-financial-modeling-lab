# Python金融建模与模拟实验

这是一套面向上海师范大学 **计算机科学与技术（数智金融）、计算机科学与技术（中法合作）** 专业大一升大二学生设计的课程。根据相关专业培养方案，学生已完成 C 语言程序设计、线性代数和高等数学的学习。本课程涵盖从金融基础、数学模型、量化研究到AI辅助的相关知识。为接下来学习的金融学、概率统计课程提供衔接。

课程在持续建设中，如果有相关课程的意见，欢迎在issue中提出。

课程采用三条同步推进的主线：

1. **金融概念线**：货币、现金流、利率、股票、债券、基金、收益、风险、组合、交易与衍生品。
2. **数学模型线**：函数、概率、统计、矩阵、优化、时间序列和随机模拟。
3. **Python能力线**：从c语言到python、NumPy、pandas、Matplotlib、交互实验、模型实现、测试和可复现研究。

## 目录

- [00_Python量化实验室.ipynb](00_Python量化实验室.ipynb)：用同一任务并排比较C与Python，逐步学习输出、变量、判断、循环和函数，再用复利问题进入NumPy、绘图与调试。
- [01_金融量化与Python初体验.ipynb](01_金融量化与Python初体验.ipynb)：从一名大学生的 10,000 元出发，认识金融系统、现金、债券、股票、基金、收益、风险和模拟研究。
- [02_现金流复利与贴现.ipynb](02_现金流复利与贴现.ipynb)：时间价值、现值、NPV、IRR、通胀与参数实验。
- [03_债券与利率风险.ipynb](03_债券与利率风险.ipynb)：固定利率债券、收益率、久期、凸性、信用风险与压力测试。
- [04_股票基金与市场交易.ipynb](04_股票基金与市场交易.ipynb)：股权、指数、基金/ETF、订单簿、价差、滑点与交易成本。
- [05_金融数据与时间边界.ipynb](05_金融数据与时间边界.ipynb)：数据审计、日期、缺失、复权、频率转换、发布时间和数据血缘。
- [06_收益率与财富路径.ipynb](06_收益率与财富路径.ipynb)：简单/对数/总回报、累计财富、年化、波动拖累与定投路径。
- [07_概率分布与抽样.ipynb](07_概率分布与抽样.ipynb)：随机变量、期望、方差、大数定律、厚尾与抽样分布。
- [08_风险度量与压力测试.ipynb](08_风险度量与压力测试.ipynb)：波动率、回撤、VaR、Expected Shortfall、状态变化、压力测试与杠杆。
- [COURSE_DESIGN.md](COURSE_DESIGN.md)：全课程备课蓝图、章节目标、模拟实践体系和评价方式。
- [AGENTS.md](AGENTS.md)：后续 Codex 备课、修改 Notebook 和批改学习记录时必须遵守的规则。
- [COURSE_STATE.md](COURSE_STATE.md)：跨对话保存的压缩课程状态。
- [requirements.txt](requirements.txt)：建议的 Notebook 依赖。

## 使用教程
本课程积极欢迎ai的参与。在课程的内容均设计可供ai读取的辅助板块。可以把课程文件夹扔给codex等ai，以实现辅助学习。

1. 在 PyCharm 中打开该文件夹/或配置Jupyternotebook打开。
2. 学习～
3. 操作滑块、修改参数，并在 `### 我的回答` 下填写文字。
4. 保存 Notebook 后。可在独立 Codex 或其它ai工具窗口中要求检查当前回答和运行输出。
5. 一章结束后执行 **Restart Kernel and Run All**，确认结果能够从零复现。

## 环境安装

建议为本项目创建独立 Python 环境，然后安装：

```bash
python -m pip install -r requirements.txt
```

如暂未安装 `ipywidgets` 或 `plotly`，基础示例仍能运行；交互单元会给出安装提示并使用静态后备图。
