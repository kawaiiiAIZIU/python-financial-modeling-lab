# Python金融建模与模拟实验

这是一套面向上海师范大学 **计算机科学与技术（数智金融）**、**计算机科学与技术（中法合作）** 专业大一升大二学生的交互式课程。默认学习者已经完成 C 语言程序设计、线性代数和高等数学，但尚未系统学习金融学、概率论与数理统计。

课程从已有数学与编程基础,向金融建模、量化研究和 AI 辅助学习衍生。帮助学生逐步学会把一个金融问题转化为变量、现金流、假设、数学模型和可以复现的计算实验。

> **建设状态**：第0—2章已经结合实际试学反馈重点修改；第3—8章已完成 Notebook 和从头运行检查，但仍处于 AI 初稿后的人工审校阶段，暂不建议直接作为正式自学材料；第9—18章目前只有课程蓝图。

课程仍在持续建设。如果发现概念跳跃、代码错误或交互体验问题，欢迎在 Issue 中提出。

## 课程设计思路

### 三条同步推进的主线

1. **金融概念线**：从“钱为什么会流动”出发，逐步进入现金流、利率、债券、股票、基金、收益、风险、投资组合、交易和衍生品。
2. **数学模型线**：把已经学过的函数、指数、极限、导数和矩阵用于金融问题，再逐步补充概率、统计、优化、时间序列和随机模拟。
3. **Python能力线**：从 C/Python 对照和语法恢复开始，逐步练习 NumPy、pandas、Matplotlib、SciPy、交互实验、函数测试和可复现研究。

## 开始学习

### 1. 准备环境

建议使用独立 Python 环境：

```bash
python -m venv .venv
source .venv/bin/activate        # Windows PowerShell 使用：.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

课程可在 PyCharm Professional、JupyterLab 或其他支持 `.ipynb` 的环境中运行。部分 IDE 对 `ipywidgets` 的嵌套图形支持不完整，因此交互实验应同时保留静态图或普通数值输出。

### 2. 推荐学习节奏

1. 从第0章开始，不要一开始跳到策略或机器学习章节。
2. 阅读问题情境，并在运行代码前完成“我的预测”。
3. 逐个运行单元格，修改参数，观察图表与普通文本输出。
4. 在 `### 我的回答` 下用自己的语言解释现象，不只粘贴代码结果。
5. 保存 Notebook，再让 AI 检查回答、代码和已经保存的输出。
6. 一章结束后执行 **Restart Kernel and Run All**，确认结果不依赖偶然的运行顺序。

### 3. 与 AI 协作

本课程允许并鼓励使用 Codex 等 AI 工具，但 AI 应作为助教和实验伙伴，而不是答案复制器。可以让 AI：

- 解释具体报错或陌生语法；
- 检查变量、单位、公式和边界情况；
- 根据保存后的输出追问金融含义；
- 提供反例、测试和调试线索；
- 批改回答，并指出相关性、因果、未来信息或过拟合等问题。

建议在独立 AI 窗口中打开整个仓库。开始新对话时，让 AI 依次读取 `AGENTS.md`、`COURSE_STATE.md` 和当前 Notebook。学生完成回答前，不应让 AI 直接填写 `### 我的回答` 区域。

## 课程边界

- 示例中的收益率、贴现率和随机过程参数主要用于教学，不代表市场报价或收益承诺。
- 模拟结果不是事实预测，累计收益曲线也不能单独证明策略有效。
- 后续真实数据与回测必须考虑日期对齐、交易成本、样本外检验和模型失效。
- 本项目用于教学与研究练习，不构成投资建议。
