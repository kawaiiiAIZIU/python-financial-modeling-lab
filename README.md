# Python金融建模与模拟实验

这是一套面向上海师范大学 **计算机科学与技术（数智金融）**、**计算机科学与技术（中法合作）** 专业大一升大二学生的交互式课程。学生已经学过 C 语言、线性代数和高等数学，但是还没有正式学过金融学、概率论和数理统计。

课程从学生熟悉的数学和程序开始。然后，它一步步进入金融建模、量化研究和 AI 辅助学习。学生会把一个真实问题拆成变量、现金流、假设和模型，再用 Python 检查结果。

## 一条连续的项目故事

整门课围绕一项连续项目展开：从10,000元奖学金出发，先做财富计算器，再比较不同选择、处理不同时点的现金流、读懂债券和股票，并修复一张有错误的数据表。数据通过检查后，项目继续研究收益、概率和风险。每一章都会留下一个可以运行和检查的作品，供下一章继续使用。

Notebook 不会先列一长串目标。项目遇到具体问题时，课程才引出需要的金融术语、数学公式和 Python 写法。

### 故事中的三条线

1. **金融线**：先问钱为什么会流动，再学习现金流、利率、债券、股票、基金、收益和风险。
2. **数学线**：先使用已经学过的函数、指数、导数和矩阵，再补充概率、统计、优化和时间序列。
3. **Python 线**：先比较 C 和 Python，再练习 NumPy、pandas、Matplotlib、SciPy、交互实验和函数测试。

## 开始学习

### 1. 准备环境

建议使用独立 Python 环境：

```bash
python -m venv .venv
source .venv/bin/activate        # Windows PowerShell 使用：.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

课程可以在 PyCharm Professional、JupyterLab 或其他支持 `.ipynb` 的软件中运行。有些软件不能完整显示 `ipywidgets` 图形，所以课程也保留静态图或普通数字输出。

### 2. 学习顺序

1. 先读第0章，不要直接跳到策略或机器学习。
2. 先看当前项目遇到的问题，再写下自己的预测。
3. 然后逐格运行代码，改参数，并观察图和数字。
4. 接着在 `### 我的回答` 下解释结果。不要只复制代码输出。
5. 保存 Notebook 后，再让 AI 检查回答、代码和输出。
6. 一章做完后，使用 **Restart Kernel and Run All** 从头运行一次。

### 3. 与 AI 协作

本课程可以使用 Codex 等 AI 工具。AI 是助教和实验伙伴，不是答案复制器。你可以让 AI：

- 解释具体报错或陌生语法；
- 检查变量、单位、公式和边界情况；
- 根据保存后的输出追问金融含义；
- 提供反例、测试和调试线索；
- 批改回答，并指出相关性、因果、未来信息或过拟合等问题。

建议在独立 AI 窗口中打开整个仓库。开始新对话时，让 AI 依次读取 `AGENTS.md`、`COURSE_REGISTRY.md`、`COURSE_STATE.md` 和当前 Notebook。学生没有作答前，AI 不能直接填写 `### 我的回答`。

## 课程边界

- 示例中的收益率、贴现率和随机过程参数主要用于教学，不代表市场报价或收益承诺。
- 模拟结果不是事实预测，累计收益曲线也不能单独证明策略有效。
- 后续真实数据与回测必须考虑日期对齐、交易成本、样本外检验和模型失效。
- 本项目用于教学与研究练习，不构成投资建议。
